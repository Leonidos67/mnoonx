# MNOONX (Alpha Space) — о продукте

## Одним предложением

**MNOONX** — платформа, на которой создатели собирают аудиторию в своё сообщество, переносят её из соцсетей, продают экспертизу (курсы и доступ) и управляют ростом через аналитику — без зависимости от алгоритмов чужих лент.

## Идеальная идея (доработанная)

Ваша ось верная. До идеала её стоит сформулировать так:

> **Не «ещё одна соцсеть», а дом для бизнеса на аудитории.**  
> Instagram / TikTok / YouTube / Telegram дают охват. MNOONX даёт **владение**: место, продукт, отношения и цифры.

### Петля продукта (north star)

```
Охват снаружи  →  Вход в сообщество  →  Ценность внутри  →  Оплата  →  Удержание + рост
     ↑                                                                      │
     └──────────────── аналитика подсказывает, что усиливать ───────────────┘
```

1. **Перегон аудитории** — создатель приводит людей ссылкой / инвайтом / Discover из своих каналов.
2. **Удержание** — лента, чат, анонсы, события, файлы: люди остаются «в доме», а не только смотрят рилс.
3. **Монетизация** — курсы, платный доступ к сообществу, продукты (Products).
4. **Аналитика** — кто пришёл, что смотрят, как растёт членство и выручка; решения по контенту и офферам на данных, не на ощущениях.

Крипто, трейдинг, фитнес, дизайн, коучинг — **вертикали внутри одной платформы**, не лицо бренда. Ниша не ограничивает ЦА; ограничивает только то, что у человека есть аудитория и чему он учит / что продаёт.

### Чем это не является

| Не это | Почему |
|--------|--------|
| Ещё один Twitter/X | Лента — слой знакомства, не главный бизнес |
| Чистый Discord | Слабая монетизация и аналитика «из коробки» |
| Только course-LMS | Без комьюнити курсы плохо удерживают |
| Только «платный чат» | Нет продукта и картины роста |

**Формула:** *Skool/Whop-логика монетизации + социальный слой + dashboard владельца.*

### Для кого

| Роль | Зачем заходит |
|------|----------------|
| Создатель / эксперт | Своё комьюнити, курсы, брендинг, контроль доступа |
| Владелец комьюнити-бизнеса | Перенос аудитории, продажа доступа, аналитика |
| Участник / ученик | Лента, чат, уроки, события — всё в одном месте |
| Нишевые вертикали (в т.ч. крипто) | Те же инструменты; контент и категории свои |

**География:** global, сильный русскоязычный старт.  
**Возраст:** ориентир 18–40 (создатели и их аудитория).  
**Языки UI:** русский и английский (i18n).  
**Маркетинг:** лендинг продукта на `/welcome` (Notion-стиль: бренд, оффер, продукт, как начать). Лента — на `/`.

## Позиционирование

**«Дом для вашей аудитории — не аренда в чужой ленте.»**

Соцсети остаются воронкой. MNOONX — место, где аудитория становится **клиентами и community**, а вы видите, что работает.

Слоганы:
- *Bring them home.*
- *Own your audience.*
- *Community. Courses. Clarity.*
- *Build. Teach. Earn.*

## Что реализовано сейчас (репозиторий Alpha Space)

Ниже — то, что **уже в коде**, в логике этой идеи.

### Аккаунт и безопасность

- Регистрация / вход (email + пароль, JWT)
- 2FA (TOTP), сброс пароля по email-коду, Pin Input для OTP
- Сессии, настройки внешних ссылок
- Login / Register с любой страницы; `RequireAuth` для профиля и Settings

### Социальный слой (воронка и удержание)

- Глобальная лента: лайки, репосты, **опросы**, **цитаты**
- Профили `/@username`, страница поста, подписки
- Discover сообществ и авторов
- Блокировки / жалобы, gate для внешних ссылок

### Сообщества — ядро продукта

- Создание сообщества (handle, описание, публичное / приватное, join-код)
- Брендинг (аватар, баннер), лента внутри community
- Права публикации для участников
- **Dashboard владельца:** обзор, пользователи, продукты, **аналитика** (рост участников, посты, оценка выручки для paid)
- Платный доступ к сообществу (`isPaid` / `price` в модели и dashboard)
- **Community Store** (apps внутри комьюнити):
  - **Courses** — главы, уроки, drip / private (продажа экспертизы)
  - Chat, Announcements, Events, Files, Content
  - Community AI, Kanban, Forms & Waitlist
- UI приложений: EN / RU

### Коммуникации и reach

- Messenger (system + Support-бот + DM), превью ссылок
- Notifications + engagement; Web Push / PWA
- Каталог Users

### UX

- Sidebar: Home, Profile, Discover, свои сообщества, Plan
- Mobile: pull-to-refresh, swipe-back; установка как PWA

## Ближайшее развитие (под north star)

Приоритет — усилить петлю «перегон → ценность → деньги → аналитика», а не расползаться в «ещё фичи соцсети».

| Приоритет | Зачем |
|-----------|--------|
| Сильные инвайты / лендинг комьюнити / share-kit для перегона с IG/TG/YT | Закрыть шаг «привести аудиторию» |
| Оплата курсов и доступа end-to-end (checkout, статусы, доступы) | Закрыть монетизацию без костылей |
| Глубже analytics: воронка вступления, прогресс по курсам, retention, топ-контент | «Подробная аналитика» как обещание продукта |
| Waitlist → paid conversion, email/push к анонсам и урокам | Удержание и дожим |
| Каталог / витрина комьюнити и курсов в Discover | Спрос с платформы, не только свой трафик |

Вторично: шаблоны постов под ниши, закладки, smart feed, wallet — только если не отвлекают от петли выше.
